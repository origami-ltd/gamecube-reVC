The source GLB is preserved as gamecube_controller.glb. The generated
gamecube_controller.dff contains the same complete static mesh converted to a
RenderWare container for runtime GX instancing. gamecube_controller.tga is the
embedded base-colour texture extracted losslessly for the native GX texture
conversion step.
